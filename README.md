# One-line gadget roast

This is a small program that writes one short text for make.fun's bounty `u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610`: one original line roasting a gadget or app you use every day, 83 characters long and written without a trailing newline.
